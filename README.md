# Гаметогенез — ашық сабақ (11-сынып, биология)

Педагог: Джумабекова Ажар Джолдыбаевна · Ащыбұлақ ЖББМ, Қазығұрт ауданы, Түркістан облысы

- `index.html` — тақта (45 мин, таймер, гид, 3D, 6 спикер, квиз басқару, рейтинг). `T` — мұғалім панелі.
- `quiz.html` — оқушы квизі (телефон), `hatshy.html` — хатшы беті (әр топқа 1 телефон).
- `lesson-data.js` — сабақтың барлық мәтіні (бір дерек көзі).
- `materialdar/` — ҚМЖ және жұмыс парақтары.
- `database.rules.json` — Firebase Realtime Database ережесі (games/… бөлімі).
